# 悬浮窗知识库搜索增强设计方案

**日期**: 2026-05-31
**状态**: 已完成
**功能**: 气泡弹窗中的知识库搜索优化

---

## 1. 背景

当前悬浮窗的"知识库搜索"标签页需要用户手动点击"搜索"按钮才能执行搜索，体验不够流畅。同时缺少搜索联想功能，用户无法快速选择已有关键词。

---

## 2. 需求分析

| 需求 | 描述 |
|------|------|
| 输入即搜索 | 用户输入关键词后自动触发搜索，无需点击按钮 |
| 搜索防抖 | 避免输入过程中频繁触发搜索，延迟 300ms |
| 搜索联想 | 基于知识库已有关键词，实时显示匹配候选 |

---

## 3. 实现方案

### 3.1 架构设计

```
┌─────────────────────────────────────────────────────┐
│              KnowledgeSearchSection                  │
│  ┌─────────────────────────────────────────────────┐ │
│  │  EditText (搜索框)                               │ │
│  │  - TextWatcher: 监听输入变化                     │ │
│  │  - OnFocusChangeListener: 显示/隐藏联想下拉      │ │
│  └─────────────────────────────────────────────────┘ │
│  ┌─────────────────────────────────────────────────┐ │
│  │  PopupWindow (联想下拉)                         │ │
│  │  - ListView: 显示匹配关键词                      │ │
│  │  - 点击联想词 → 填充输入框 + 执行搜索            │ │
│  └─────────────────────────────────────────────────┘ │
│  ┌─────────────────────────────────────────────────┐ │
│  │  ScrollView + LinearLayout (搜索结果列表)        │ │
│  └─────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────┘
```

### 3.2 组件说明

| 组件 | 职责 |
|------|------|
| `EditText` | 搜索输入，带 TextWatcher 监听 |
| `PopupWindow` | 联想下拉容器，跟随输入框位置 |
| `ListView` | 联想词列表，最多显示 5 条 |
| `Handler` | 300ms 防抖延迟，延迟后执行搜索 |
| `serviceScope` | 在 IO 线程查询知识库关键词和规则 |

### 3.3 流程说明

**联想流程（输入框获得焦点且有内容）：**
1. 用户输入 → TextWatcher 触发
2. 300ms 防抖
3. 查询知识库关键词（包含输入字符）
4. 显示匹配结果（最多 5 条）
5. 用户点击联想词 → 填充输入框 → 执行搜索

**搜索流程（输入停止 300ms）：**
1. TextWatcher 检测输入变化
2. 300ms 防抖延迟
3. 调用 `performKnowledgeSearch()`
4. 显示搜索结果

## 5. 交互细节

### 5.1 搜索框行为

| 场景 | 行为 |
|------|------|
| 输入变化 | 300ms 后触发搜索，同时更新联想列表 |
| 获得焦点 | 显示联想下拉（如果有匹配结果） |
| 失去焦点 | 隐藏联想下拉（延迟 200ms 避免点击失效） |
| 清空输入 | 隐藏联想下拉 |

### 5.2 联想下拉行为

| 场景 | 行为 |
|------|------|
| 无匹配 | 不显示或显示空提示 |
| 有匹配 | 显示最多 5 条关键词 |
| 点击联想词 | 填充输入框 + 立即执行搜索 |
| 滚动 | 支持上下滑动选择 |

### 5.3 防抖逻辑

```
用户输入 "退" → TextWatcher → 300ms 后 → 显示联想 + 执行搜索
用户继续输入 "退款" → TextWatcher → 重置 300ms → 更新联想 + 搜索
用户清空 → TextWatcher → 隐藏联想下拉
```

---

## 6. 性能考虑

- **防抖**: 避免输入过程中频繁搜索
- **异步**: 知识库查询在 IO 线程执行
- **限制**: 联想结果最多 5 条，避免界面拥挤
- **延迟关闭**: 失去焦点后延迟 200ms 再关闭，给点击事件留出时间
