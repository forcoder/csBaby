# 云端同步功能 - 产品提案

## 1. 问题陈述

### 1.1 背景

客服小秘 (csBaby) 是一款 Android 智能客服回复辅助工具。当前版本支持本地存储知识库规则和 AI 模型配置，但存在以下问题：

- **数据丢失风险**：用户卸载 App 或更换设备时，本地数据无法迁移
- **多设备不同步**：同一用户在不同设备上使用，数据各自独立，无法共享
- **无备份机制**：缺乏云端备份能力，数据安全性不足

### 1.2 影响

| 问题 | 影响范围 | 严重程度 |
|------|---------|---------|
| 数据丢失 | 所有用户 | 高 |
| 多设备不同步 | 多设备用户 | 中 |
| 无备份 | 所有用户 | 中 |

### 1.3 当前解决方案

用户需要手动导出/导入数据，或依赖第三方备份工具，操作繁琐且不可靠。

---

## 2. 解决方案概述

### 2.1 目标

实现**云端同步功能**，让用户数据在多设备间自动同步，并提供可靠的数据备份能力。

### 2.2 核心价值

| 价值主张 | 描述 |
|---------|------|
| 数据安全 | 云端备份，数据永不丢失 |
| 多设备同步 | 同一账号，数据实时同步 |
| 无缝迁移 | 换手机一键恢复所有数据 |

## 3. 功能规格

### 3.1 核心功能

#### F1: 用户认证
- 邮箱 + 密码注册/登录
- JWT Token 认证（Access Token 24h + Refresh Token 30d）
- 登录状态持久化

#### F2: 全量同步
- 首次登录自动拉取云端数据
- 卸载重装后一键恢复
- 手动触发全量同步

#### F3: 增量同步
- 变更即同步（2s debounce）
- 基于 syncVersion 增量推送
- 基于时间戳增量拉取

#### F4: 冲突处理
- 服务端数据优先级：知识库规则、AI模型、消息黑名单
- 客户端优先级：用户风格画像
- 合并策略：应用配置
- 无法自动合并时 UI 提示用户选择

#### F5: 数据备份（旧版兼容）
- 全量数据 JSON 上传
- 备份列表查询
- 历史备份下载/删除

### 3.2 同步数据类型

| 数据类型 | 说明 | 同步策略 |
|---------|------|---------|
| 关键词规则 | 知识库规则 | 增量 |
| AI模型配置 | API Key 等 | 增量 |
| 用户风格画像 | 个人风格学习数据 | 增量 |
| 应用配置 | 监控应用列表 | 增量 |
| 场景配置 | 自动化场景 | 增量 |
| 回复历史 | 历史回复记录 | 增量 |
| 消息黑名单 | 屏蔽规则 | 增量 |

### 3.3 同步时机

| 时机 | 触发条件 |
|------|---------|
| 首次登录 | 自动全量拉取 |
| App 启动 | 检查同步点，增量同步 |
| 数据变更 | 2s debounce 后自动同步 |
| 手动触发 | 用户点击"立即同步" |
| 退出应用 | 自动保存 |

## 4. 用户体验

### 4.1 用户流程

```
[打开 App]
     ↓
[检查登录状态]
     ↓
[已登录] → [恢复认证状态] → [全量同步/增量同步]
     ↓
[未登录] → [登录/注册页面]
     ↓
[同步完成] → [进入首页]
```

### 4.2 状态显示

| 状态 | UI 显示 |
|------|---------|
| 空闲 | 无提示 |
| 同步中 | "正在同步..." + 进度指示 |
| 成功 | "同步完成" (3s 后消失) |
| 失败 | "同步失败: [错误信息]" + 重试按钮 |

### 4.3 错误处理

| 错误类型 | 处理方式 |
|---------|---------|
| 网络错误 | Toast 提示 + 重试按钮 |
| Token 过期 | 自动刷新 / 提示重新登录 |
| 服务器错误 | 记录日志 + 友好提示 |
| 数据冲突 | 显示冲突对话框让用户选择 |

| SyncApiService | Retrofit API 定义 |
| SyncQueue | 离线变更队列 |
| SyncCheckpointDao | 同步检查点存储 |

### 5.3 后端 API

|------|------|------|
| /auth/register | POST | 用户注册 |
| /auth/login | POST | 用户登录 |
| /auth/refresh | POST | Token 刷新 |
| /sync/all | GET | 全量拉取 |
| /sync/changes | GET | 增量拉取 |
| /sync/push | POST | 增量推送 |
| /sync/resolve | POST | 冲突解决 |

## 7. 风险与依赖

### 7.1 风险

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| 后端服务不可用 | 无法同步 | 本地优先读取，离线队列 |
| Token 泄露 | 数据安全 | HTTPS + 加密存储 |
| 冲突处理复杂 | 用户体验 | 简化冲突策略，默认服务端优先 |

### 7.2 依赖

| 依赖项 | 状态 | 说明 |
|--------|------|------|
| 后端服务 | 已部署 | https://csbaby-sync-server.onrender.com |
| PostgreSQL | 已部署 | 租户数据隔离 |
| JWT 库 | 已集成 | Node.js jsonwebtoken |

## 8. 验收标准

### 8.1 功能验收

- [ ] 用户可以注册/登录账号
- [ ] 登录后自动触发全量同步
- [ ] 本地数据变更自动同步到云端
- [ ] 云端数据变更自动同步到本地
- [ ] 卸载重装后数据恢复成功
- [ ] Token 过期后能正确刷新或提示重新登录
- [ ] 同步状态正确显示

### 8.2 性能验收

- [ ] 全量同步（1000 条规则）< 30s
- [ ] 增量同步 < 5s
- [ ] 同步不阻塞 UI 操作

### 8.3 安全验收

- [ ] Token 加密存储
- [ ] HTTPS 通信
- [ ] 租户数据完全隔离
